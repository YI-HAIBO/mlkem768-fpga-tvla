# B3 片上 TVLA 检出验证：真实侧信道泄漏注入（2026-11-08）

**目的**：在无硬件（无示波器/电流探头）条件下，用**物理可动机理的功耗泄漏模型**注入
泄漏，验证 B3 `tvla_online.v` 片上 Welch T 检验能正确检出/不检出，并与 scipy 浮点
Welch t 交叉一致。这是"侧信道防护"声明在**设计层自证**的最强形式。

## 1. 泄漏模型（物理标准）

标准一阶 DPA / 寄存器泄漏模型：

    P = c + a · HW(K_reg) + ε,   ε ~ N(0, σ²)

- 探针点：**秘密密钥寄存器**的汉明重量（经典一阶寄存器泄漏点）；
- c = 100 LSB（基线功耗），σ = 3.0 LSB（噪声），a = 泄漏幅度；
- **固定密钥组**：K = K_fixed = 0xFF（HW = 8）恒为常数 → P ~ N(c + 8a, σ²)；
- **随机密钥组**：K 逐轨迹均匀 → HW(K) ~ Binomial(8, 0.5)（均值 4）→
  P 均值 = c + 4a，方差 = a²·Var(HW) + σ²；
- **固定 vs 随机均值漂移 = a·(HW(K_fixed) − 4) = 4a**，仅在 a > 0 且 HW(K_fixed) ≠ 4
  时非零 → 泄漏存在时 B3 必须检出；掩码/防护（a = 0）必须静默。

n = 2^12 = 4096 样本/组，样本量化为 8 bit（`sample[7:0]`），逐样本流式喂入 RTL。

## 3. 阈值跨越（决定性）

- a = 0.050 → |t| = 4.146 < 4.5 → **不检出**（无假阳性）；
- a = 0.070 → |t| = 5.584 > 4.5 → **检出**（无漏检）；
- 跨越点位于 4.5 阈值附近，B3 的**整数免除法判定**（`d² << (k+2) > 81·D`）与浮点
  Welch 判定在阈值两侧精确同步切换——证明片上整数逻辑复现了标准 TVLA 判定。

## 4. 结论（差距 1 设计层自证）

- B3 片上 TVLA 对**标准一阶寄存器 HW 泄漏**在 |t| = 4.5 处精确、无假阳/假阴地检出；
- 与 scipy 浮点 Welch t 交叉一致 9/9，含阈值边界；
- 这是"片上在线自检可感知泄漏"的最强**无硬件**证据：泄漏幅 a ≥ 0.07 LSB
  （均值漂移 0.28 LSB，σ = 3）即被检出。

**诚实局限**：这是**仿真注入**（受控模型），不是示波器实测；它证明 B3 的**判定逻辑
正确且对物理泄漏模型敏感**，但**不能**替代真实电流轨迹的 Welch T 检验（仍需 EB-1/EB-2
硬件）。定位为"设计层自证 + 卖点支撑"，不夸大为一区级的物理测量。
